关于项目

为 DIY 玩家准备的线上牌桌

在线上玩自己 DIY 的武将，最麻烦的往往不是设计，而是实现——要么学会写代码，要么忍受各种规则引擎的限制。

南瓜牌桌选择了另一条路：像面杀一样，手动操作每一张牌。你可以拖拽、旋转、翻面、摊牌、叠牌，随意处理牌堆与手牌区，而不需要为任何一张 DIY 武将写一行代码。

只要你和朋友们熟悉面杀规则，就能在线上还原一场完整的三国杀。

项目由十二引工作室开发，官方 QQ 群长期提供扩展包与技术支持，欢迎所有三国杀 DIY 爱好者加入。

常见问题

你可能想问

南瓜牌桌是免费的吗？
是的，项目完全免费，并且持续更新。你可以从 GitHub Releases 或官方 QQ 群获取最新版本和扩展包。
支持哪些操作系统？
支持 Windows 与 macOS。跨平台联机已经过多轮测试，Mac 连 Windows 也能正常工作。
联机需要自己搭服务器吗？
不需要专门搭服务器。房主在软件内创建服务端，其他玩家输入 IP 即可连接。如果双方不在同一局域网内，需要使用 TCP 协议的内网穿透隧道。
我需要会编程才能 DIY 武将吗？
完全不需要。南瓜牌桌的设计初衷就是让 DIY 玩家不必学习代码——所有武将、牌堆、标记都通过扩展包配置，进入牌桌后手动操作每一张牌即可。
扩展包和资源包有什么区别？
扩展包（.pct）作用于对局内的武将、牌堆和标记，直接影响怎么玩；资源包作用于本地展示，比如背景图片和音效，不影响任何操作，纯个性化。
和桌游模拟器（TTS）有什么区别？
南瓜牌桌专为三国杀 DIY 场景设计，内置了身份牌、体力牌、手牌区、弃牌堆、牌盒、牌堆等三国内核所需的元素，并提供检索、堆牌、摊牌、座位圆盘等针对性功能，操作习惯更贴近面杀。
